# Catálogo e mídia

## Regra de publicação
- Só publicar hero quando a mídia for `verified`.
- `probable` pode aparecer com cautela.
- `needs_review`, `placeholder` e `rejected` não podem fingir foto real.

## Para aprovar um SKU
- Nome, slug, descrição e categoria precisam concordar.
- A imagem hero precisa bater com o produto.
- A galeria só pode ter imagens do mesmo item.
- Se houver dúvida, marcar para revisão.

## Operação
- Verifique o status de mídia no card e no PDP.
- Revise itens bloqueados antes de publicar.
- Não use imagem parecida como substituto.
