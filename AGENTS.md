# AGENTS.md — regras operacionais do repositório MDH 3D

## Verdade acima de velocidade
Nunca diga que algo está pronto sem:
- build
- teste
- commit
- push tentado
- prova objetiva

## Não fazer
- não criar arquitetura paralela
- não destruir layout atual
- não fingir mídia real
- não fingir integração pronta
- não esconder erro crítico
- não encerrar com pendência silenciosa

## Fazer
- auditar antes de editar
- preservar o que funciona
- corrigir raiz do problema
- documentar pendências reais
- preferir mudanças pequenas e verificáveis
- manter compatibilidade com Next.js App Router

## Ecommerce
- catálogo funcional
- PDP funcional
- carrinho global
- checkout funcional
- área do cliente
- admin utilizável
- histórico de compras
- SEO coerente
- structured data coerente
- mídia semanticamente correta

## Catálogo e imagens
- hero precisa representar o produto
- imagens extras precisam representar o mesmo item
- bloquear item duvidoso é melhor que publicar item enganoso

## Final obrigatório
Toda tarefa deve terminar com:
1. diagnóstico
2. implementação
3. arquivos alterados
4. resultado de lint/typecheck/build/tests
5. status do commit
6. status do push
7. pendências restantes
